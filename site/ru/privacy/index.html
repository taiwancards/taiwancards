Политика конфиденциальности

Дата вступления в силу: 1 марта 2025 года

Назначение приложения

TaiwanCards — бесплатное веб-приложение без рекламы, предназначенное для изучения тайваньского мандарина. Оно предоставляет карточки с интервальным повторением, поиск по словарю, тренировку произношения и списки лексики. Приложение разрабатывается и поддерживается одним независимым разработчиком, а не компанией.

Какие данные обрабатываются

  • Адрес электронной почты, отображаемое имя и язык интерфейса.
  • Ваш пароль не хранится: учётная запись создаётся через Google, и приложение никогда не запрашивает пароль.
  • Учебные данные: колоды, карточки, история повторений, прогресс и настройки тренировок.
  • Попытки произношения и вычисленные на их основе измерения.
  • Журналы серверных запросов, сохраняемые в целях обеспечения надёжности работы и предотвращения злоупотреблений.

Что не осуществляется

  • Персональные данные не продаются и не предоставляются во временное пользование.
  • Реклама не размещается, рекламные трекеры не используются.
  • Сторонние системы аналитики не применяются.
  • Профилирование не осуществляется ни для каких целей, кроме отображения пользователю его собственных результатов.

Файлы cookie

Используются два файла cookie, оба строго необходимые: подписанный сессионный файл, обеспечивающий сохранение входа в учётную запись, и файл, сохраняющий выбранный язык интерфейса. Рекламные и отслеживающие файлы cookie не используются.

Кнопка пожертвования

На странице помощи размещена необязательная кнопка пожертвования, предоставляемая сервисом Buy Me a Coffee. При открытии указанной страницы загружается их скрипт, вследствие чего браузер пользователя обращается к их серверам, и им становятся доступны IP-адрес и строка user agent. Данные учётной записи не передаются, на других страницах кнопка отсутствует, совершение пожертвования не является обязательным.

Вход через Google и ваши данные

Вход через Google — необязательный способ создать аккаунт. Можно зарегистрироваться и обычной почтой с паролем, тогда никакие данные Google не запрашиваются вовсе.

  • При входе через Google TaiwanCards получает ваш адрес электронной почты и имя из профиля. Это нужно, чтобы создать учётную запись и связать с ней ваш прогресс.
  • Если вы отдельно нажмёте «Сохранить в Google Drive», приложение создаст на вашем Диске один файл с резервной копией вашего учебного прогресса и сможет читать и перезаписывать только его.
  • Права ограничены разрешением drive.file: доступ есть только к тем файлам, которые создало само приложение. Остальные файлы на вашем Диске TaiwanCards не видит и получить к ним доступ не может. Резервная копия не создаётся автоматически — только по вашему нажатию.

Использование сведений, полученных через API Google, соответствует политике Google API Services User Data Policyи её требованиям Limited Use. Данные аккаунта Google никогда не используются для рекламы, никогда не продаются и никому не передаются сверх описанного здесь.

Место обработки данных

Приложение и его база данных размещены на Render в Сингапуре. Трафик проходит через Cloudflare, аудиофайлы отдаются из Cloudflare R2. Указанные поставщики обрабатывают данные исключительно в целях размещения сервиса. При использовании резервного копирования в Google Drive соответствующая копия находится в вашей собственной учётной записи Google.

Сроки хранения и удаление

Данные хранятся в течение всего срока существования учётной записи. Для удаления учётной записи и всех связанных с ней данных направьте запрос на указанный ниже адрес; серверные журналы удаляются по истечении срока их хранения. Удаление учётной записи не затрагивает резервный файл, созданный вами в вашем Google Drive, — такой файл удаляется вами самостоятельно.

Права пользователя

  • Пользоваться словарём, грамматикой, справочными разделами и всем о Тайване вовсе без учётной записи.
  • В любой момент отозвать доступ приложения к Google на странице разрешений вашей учётной записи Google.
  • Запросить копию своих данных, их исправление или полное удаление.

Несовершеннолетние

Приложение не адресовано детям младше 13 лет; учётные записи для них сознательно не создаются.

Изменение политики

При изменении настоящей политики одновременно обновляется указанная выше дата вступления в силу.

Обратная связь

Вопросы, запросы на предоставление данных и запросы на удаление: support@taiwancards.app
